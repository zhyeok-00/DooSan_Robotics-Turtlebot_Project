# 안전 설계 및 시험 절차

## 소프트웨어 안전장치

- `WAIT_COMMAND`에서 정렬, 잔탄, 재장전 완료, 사람 승인 조건을 모두 만족해야만 `fire_ready`를 발행합니다.
- `TRACK` 진입 시 이전 세션의 방향·거리 값을 폐기합니다.
- 새 방향과 거리 신호가 모두 도착하기 전에는 `cmd_vel=0`을 유지합니다.
- 두 신호 중 하나가 타임아웃되거나 NaN, 무한대, 0 이하 거리이면 정지 후 추적을 종료합니다.
- 조준 회전 속도는 최대값과 가속도 변화율로 제한합니다.
- 모드가 바뀌는 순간 기존 제어 노드는 정지 명령을 한 번 발행하고 이후 토픽 소유권을 넘깁니다.
- 노드 종료 시 마지막 정지 명령을 발행합니다.

## 실제 로봇 시험 체크리스트

1. 바퀴가 지면에서 뜬 상태에서 토픽과 회전 방향을 확인합니다.
2. 물리 슈터의 탄약을 제거하고 승인·발사 핸드셰이크를 검사합니다.
3. `cmd_vel` 발행자를 `ros2 topic info --verbose`로 확인합니다.
4. 방향 또는 거리 토픽을 끊어 제한 시간 안에 정지하는지 확인합니다.
5. NaN, 음수 거리, 오래된 입력을 주입해 전진하지 않는지 확인합니다.
6. 비상 정지 수단과 충분한 안전거리를 확보한 후 저속으로 바닥 시험을 시작합니다.
7. 마지막으로 탄약을 장착하고 사람 승인 경로를 포함한 통합 시험을 수행합니다.

## 알려진 한계

- 현재 `cmd_vel` 소유권은 상태 규약에 의존합니다. 운영 환경에서는 `twist_mux` 같은 명시적 중재기와 하드웨어 비상 정지를 추가하는 것이 권장됩니다.
- YOLO 인식 결과는 안전 센서가 아닙니다. 장애물 회피와 충돌 방지는 Nav2 및 로봇 기본 안전 기능에 의존합니다.
- UI 비밀번호 입력은 시연용이며 실제 인증 또는 발사 안전 인터록으로 간주하면 안 됩니다.
