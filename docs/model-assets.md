# 모델 가중치 공개 점검

프로젝트 원본에는 다음 학습 가중치가 사용되었지만, 공개 저장소의 Git 기록에서는 제외합니다.

| 파일 | 용도 | 공개 전 필요한 확인 |
|---|---|---|
| `ros2/perception_ws/src/yolo_detector/y11s_my_best.pt` | 상대 로봇 탐지 | 학습 데이터 출처, Ultralytics 버전, 재배포 권한 |
